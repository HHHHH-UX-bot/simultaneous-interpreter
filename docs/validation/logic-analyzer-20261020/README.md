# 逻辑分析仪接线前准备

核验日期：2026-10-20；范围仅为电脑 USB 识别和探针未接板卡时的限定采样，不是串口信号验收。当前结论、接线缺口和下一步由 [ENGLISH](../../context/ENGLISH.md#tls-传输诊断进行中2026-10-20)维护。

- [设备扫描](probe.json)：使用用户资料包内 libsigrok 0.6.0，扫描得到 SIPEED / USB TO LA / SI 8ch。Windows 标识为 `USB\VID_359F&PID_0300\SI_8CH`，设备状态 OK。
- [空载采样](smoke.json)：8 通道、20 MS/s、200 万点，收到 200 万个单字节采样及结束标志。样本覆盖 0.1 秒，wall_seconds 含软件启动和收尾；未接板卡，不能验证 UART 波形、输入电压或采样准确率。
- [工具与来源](preparation.json)：原包和 DLL 的指纹、官方型号/电压资料、采集警告及接线状态。

便携库在空载采样时大量输出 `WaitForMultipleObjectsEx failed`。单独初始化 Winsock 的对照仍有同类警告；正式长时捕获尚未放行。官方当前驱动源码描述过同类负值定时器键被指针截断转为正值的问题，但尚未证明当前 DLL 的具体实现或完成工具修复。

原始空载数据、日志和临时探测脚本仅位于被 Git 忽略的 output/、tmp/；不分发外部软件包，不在此记录密钥、音频或通信载荷。没有因本准备阶段改动开发板程序、接线或固件。
