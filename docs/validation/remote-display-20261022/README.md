相同六句、每句25–29汉字、40.129秒夹具，启用实时网口画面和CPU1触摸。自测ELF `1b76595f753a928ab8ea3b21a98118c2a96d0176ade2b33793bb987ef7eb86e0`：13条ASR/译文、13段完整译音，ASR匹配1.0；1,056,000个PCM样本全部播放，单次TLS，零故障/恢复、丢页、播放欠载、串口溢出/帧错误和解析错误。末输入到最后译文6.604秒、到全部DAC播完12.562秒；合成译音总长44秒，计时并非实体麦克风到扬声器声学延迟，也不构成长时间或双向质量验收。
