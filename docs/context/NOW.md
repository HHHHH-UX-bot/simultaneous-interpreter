- 当前产品采用仅文本云响应，保留既有 PL 本地回环；数字 L1=62 µs 的证据不等于耳机听感或声学时延通过。L1/T1 已用 PS 抗锯齿卡片显示，旧 PL 像素字符层已关闭。
