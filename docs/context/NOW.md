- 实际麦克风 → PL 16 kHz PCM → PS 固定点 Opus/Ogg → ARM TLS → ESP8266 TCP/Wi-Fi → 百炼 → 英中字幕预览已通过用户短验收；菜单支持 English → Chinese / Chinese → English，触摸及三档实际字幕字号均有实屏证据。
- 当前产品采用仅文本云响应，保留既有 PL 本地回环；数字 L1=62 µs 的证据不等于耳机听感或声学时延通过。L1/T1 已用 PS 抗锯齿卡片显示，旧 PL 像素字符层已关闭。
- 仅字幕固定英文样本通过 1830.1 秒、174 条新定稿的单连接观察，属于当时自测 ELF。真实麦克风多句、静默和双向切换长期可靠性仍未放行，不把固定样本长测扩展为整机通过。
- 当前 ARM TLS 双语模型已保留最近64条真实定稿；独立历史页、英中逐行对齐、滑动/翻页、页内确认清空已实现。浏览器早期弹层不作板端证据；真实USB滑动/翻页/返回已获本轮用户验收，清空语义由板端命令检查。
