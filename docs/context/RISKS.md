- R24：Opus/Ogg 已降低输入带宽并支持真实语音；不以码率下降宣布全部网络/服务错误解决。

## 本轮约束

历史页实现不得依赖先修 R28；因此可用合法的离线定稿夹具验证 UI，必须标为模拟并与真实采音分开。实际云端若仍不能定稿，历史为空必须如实显示。进入/退出历史不重连、不暂停，清空只删除历史，避免把 UI 操作当作队列恢复手段。
