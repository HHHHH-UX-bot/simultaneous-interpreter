# 风险与验证缺口

## 2026-10-21 字幕优先范围

带译音的字幕停更仍未确定根因；仅字幕固定样本在 CYEA 下通过 30 分钟并持续产出有效双语定稿，不能反向给译音或其他网络放行。随后修正本地 DAC 选择并取得真实麦克风/触摸/画面短验收，耳机听感、声学时延及真实麦克风长期整机仍待完成，证据由[本轮验证](../validation/text-response-20261021/README.md)维护。回环复用既有 PL，无新增硬件资源；用户允许在资源或稳定性确实受影响时取消，目前未触发该条件。

## 2026-10-20 英文触摸与链路

当前英文候选存在枚举成功但零原始触摸报告、USB 清 RS 停机间歇超时，以及 TLS fatal alert 后 AT 超时。新旧触摸 ELF 均有成功和失败记录，未确定版本或硬件根因。保留失败证据和 DMA Halt 门禁；恢复成功、标签变化及短时译文都不代表可靠性通过。当前范围与下一步由 [ENGLISH](ENGLISH.md#当前阶段触摸控制与时延界面2026-10-20)维护。

## 2026-10-20 中译中共享传输

实际加载副本仅有短时采集/上传就绪证据；本 PR 在共享主线启用中译中并重新验证，但没有再次上板。两种来源、哈希和仍需真人/长测验收的范围由 [ZHZH](ZHZH.md#验证与来源) 维护。密钥、随机种子与时钟仍是运行时输入；不关闭认证，不将单次连通或中译英历史长测当作中译中已稳定。
