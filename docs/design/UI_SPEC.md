# 7 英寸字幕终端 UI 设计

日期：2026-10-10。本文是界面布局与交互的权威规范。产品功能边界见 [SYSTEM_PLAN](SYSTEM_PLAN.md)，异步结果归属见 [INTERFACES](INTERFACES.md)，当前验收见 [NOW](../context/NOW.md)。

## 设计参考及取舍

用户要求参考网上 skill 或成熟方案。本轮已阅读 [Anthropic frontend-design SKILL](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)，采用先定义视觉方向、再实现并截图审查的方法。外部规则作为参考，不安装技能包、不照搬其示例文案，也不覆盖本项目 AGENTS。

字幕使用参考 [Google Live Transcribe](https://support.google.com/accessibility/android/answer/9158064) 的大字号、记录、原文阅读与语言入口思路。它是转写产品，不代表本项目具备其算法能力；这里的“暂停”明确停止采集/发送，与只冻结阅读画面的功能分开。

触控参考 [Android 可访问性](https://developer.android.com/guide/topics/ui/accessibility/apps) 的较大可点区域与文字对比，以及 [W3C 目标尺寸解释](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)。Android dp、CSS px 与硬件像素不能直接等同：本产品最终需在实屏确认手指触控大小，原型按 56×56 逻辑像素以上设计常用控件。

正式移植时使用 [LVGL Button 状态与事件](https://lvgl.io/docs/open/widgets/button)，配合 Label、List、Switch、Dropdown 和对话框；保持按下、选中、禁用、聚焦的区别，避免只用颜色暗示设备状态。

## 视觉方向与两种布局取舍

用途是连续阅读字幕；选择安静的浅色阅读面、深色文字和单一青绿色动作重点，不使用大量指标卡、背景渐变或装饰动效。

- 方案 A：左右对半原文/中文。并行对照方便，但压缩中文行长，7 英寸大字易碎成短行。
- 方案 B：中文主阅读区，原文在其下，右侧窄会话记录。让中文占据核心面积、原文保持可选；本轮采用 B。

外部 skill 的网页 hero 或手机整页布局没有直接搬来。本产品把“当前中文”作为视觉重点，屏幕边界固定，所有常用操作留在同一位置。

### 设计 token

| 名称 | 值 | 用途 |
|---|---|---|
| 阅读面 | `#FFFFFF` | 当前字幕与弹层 |
| 外层底色 | `#EDF3F5` | 降低面板之间干扰 |
| 主文字 | `#172A38` | 中文字幕与标题 |
| 次文字 | `#526575` | 原文、说明和时间 |
| 主动作 | `#006C68` | 开始/继续、当前选择 |
| 警示文字 | `#9C3B22` | 过载或不可继续原因，配合明确文案 |

电脑预览中文优先使用“微软雅黑”，英文沿用系统无衬线字体，目的是看清长时间阅读的笔画。本轮不加载外部字体；板端字库单独选型并验证。普通正文目标对比度至少 4.5:1，按钮与状态有文字和形状，不单靠颜色。

字号：中央译文 28/36/44 px 三档。浏览器原型默认 36，当前云端会话首次启动用 28，重连保留用户选择；原文和历史在板端固定为 28，区域标题和控件固定为 18，时间/辅助标签最小 14。A+/A− 只改变中央译文，不改变区域标题或原文。中文行高约 1.45；避免把长句强制缩成小字号。

板端常用汉字仅保存一份 28 px 字库；36/44 原生字集中没有的常用汉字，从该字库按相同 advance 比例进行双线性覆盖率缩放。已有各字号原生字形优先使用，未知字符仍用替代框；保持原 2 MiB 字库分区，字号改变后重新换行。不能用底部“小/中/大”标签变化代替实际非空译文的字号验收。

## 布局

目标逻辑区域为 1024×600。浏览器窄窗口等比例缩放只是预览方式，不作为手机布局或板端实际触控尺寸验收。

```text
┌──────────────────────────────────────────────────────────────┐
│ 译声    当前语言 → 简体中文          会话状态   演示标识       │ 64
├─────────────────────────────────────────────┬────────────────┤
│ 中文字幕            定稿/翻译状态             │ 本次会话        │
│                                             │ 用时 / 句数     │
│ 大字号当前译文                              │ 输入状态        │
│                                             │                │ 444
│ 状态提示：保留上句 / 正在处理 / 下一步         │ 最近定稿记录    │
├─────────────────────────────────────────────┤ 可点开全部      │
│ 原文（可隐藏、长句可滚动）                    │                │
├─────────────────────────────────────────────┴────────────────┤
│ 开始/暂停    清空记录     原文开关     字号 −/+        设置     │ 92
└──────────────────────────────────────────────────────────────┘
```

外边距 24 px，内容纵向间距 16–20 px；右列约 248 px，中文主列使用剩余空间。主要触控目标至少 56×56 px、相邻间距至少 8 px。当前字幕和原文独立滚动，固定底栏不被长句推出屏幕。

## 页与弹层

| 视图 | 内容与操作 |
|---|---|
| 主字幕 | 当前中文、可选原文、明确处理阶段、开始/暂停、字号、原文和设置 |
| 会话记录 | 最近定稿预览；全部记录可滚动，原文和中文成对展示，可导出演示文本 |
| 设置 | 源语言、字体、原文显示；只显示实际后端声明可用语言。原型语言为演示文案，真实配置待确认 |
| 清空确认 | 说明将停止当前演示并清除本次记录；取消/清空，默认聚焦取消 |
| 错误反馈 | 主区域内给出原因与下一步，保留最后定稿；禁止只有红灯或堆栈报错 |

阅读历史或设置不暗中开始录音；真实产品进入改语言流程应先暂停，并明确开启新会话。原型打开设置时暂停演示；调整字号或原文开关可直接生效。对话框支持 Escape 关闭、Tab 聚焦，并阻止背景按钮被误点。

## 字幕行为与场景

| 状态/场景 | 阅读区行为 | 主操作 |
|---|---|---|
| 就绪/空内容 | 提示点击开始，标明示例文案与模拟状态 | 开始翻译 |
| 监听 | 保留上一条定稿，输入指示变化，提示正在聆听 | 暂停 |
| 识别草稿 | 更新原文当前段，不写入历史；中文继续保留上一条 | 暂停 |
| 翻译中 | 标注翻译中，不冒充已定稿；可持续显示上一句 | 暂停 |
| 定稿 | 更新当前中文、按段去重写入记录 | 暂停/继续 |
| 暂停 | 保留定稿，未定稿取消或明确标记 | 继续翻译 |
| 静音 | 显示没有检测到语音，不产生虚构新字幕 | 暂停 |
| 无音频模块 | 保留译文，提示先连接音频模块 | 检查输入（原型提示恢复演示） |
| 后端断开 | 保留译文，说明本段中断；恢复不回填缺口 | 重新连接（原型恢复模拟连接） |
| 输入过载 | 警告声音过大，实际需调整硬件/配置增益 | 检查输入，不假造增益控制 |
| 长句 | 中文和原文各自换行/滚动；历史可展开完整内容 | 字号与记录入口仍可点 |

中文定稿不会字符闪烁或频繁清空；下一段处理时保留上一句。停止演示时取消定时任务，清空后旧会话结果不能再次出现。细节以 INTERFACES 为准。

### 板端云连接提示

当前 ARM TLS 应用将传输状态与识别阶段一起显示。点击继续或开始后显示 `Connecting` 和“正在连接服务，准备好后再说话。”；只有云客户端收到 `session.updated`、进入实际音频流阶段，且网络仍连通，才显示 `Ready` /“已就绪，可以开始说话。”。AT 成功、TLS 握手成功或发出会话配置本身都不代表就绪。

暂停显示 `Paused` 和继续提示；实际网络/云事件故障显示 `Offline` 和重试提示，自动重连时重新显示 Connecting。沿用原有重连策略，不新增重试。等待、故障和暂停都保留上一句定稿；等待/离线的服务指示条保持静止。识别草稿、翻译和定稿仍使用原阶段标签。非 ARM TLS 构建保留原 Listening 语义，未宣称支持这套连接提示。

这些提示不表示录音音量、端到端延时、网络质量或全产品可靠性；实现与验收由 [ENGLISH](../context/ENGLISH.md#云端连接就绪提示2026-10-20)维护。

### 时延读数

用户 2026-10-20 要求优化 L1/T1，明确不采用与界面不一致的像素风。当前由 [ui_render.c](../../software/subtitle_ui/ui_render.c) 使用原 UI 的抗锯齿字库绘制；PL 保留测量寄存器，关闭旧字符覆盖，但保留 RGB/DE/HS/VS 同拍寄存级。

| 项 | 约定 |
|---|---|
| 位置 | 顶部两张 104×48 圆角卡片：x=492..595、604..707，y=8..55；不遮挡字幕、语言标题或按钮 |
| 风格 | 现有 14/18 px 抗锯齿字体；浅底、细边、青绿色数值，单位单独对齐；不显示前导零 |
| L1 LOOP | 数字 ADC→回环逻辑的测量值，单位 us；不代表声学延迟，也不代表云端译音 DAC 输出延迟 |
| T1 TEXT | 收到云端 speech-start 事件到收到首条 ASR/翻译文字的时间，单位 ms；不包含完整上行/显示链路，不能称为麦克风到屏幕端到端延迟 |
| 状态 | 未测得显示 `--`；超过显示范围为 `9999+`；新 VAD 测量开始、暂停或连接停止时 T1 清为未测得，不把上句读数当作本句 |
| 刷新 | 每次 PS 双缓冲绘制前采样，随现有约 500 ms UI 周期更新；CTRL.bit2 可冻结读数 |
| 快照 | v2 在 reserved 字段中保存两路读数，各 16 位（valid/超量程/14 位数值）；原生像素对照从同一快照重建卡片。当前语言菜单版模型/快照为 11392/11456 字节；菜单前历史版为 11384/11448，按 header 中的 model_bytes/bytes 区分，不能混用 |

L1 测量定义与门禁见 [AUDIO_LOOPBACK](AUDIO_LOOPBACK.md#4-时延测量定义)。原生预览数值仅为排版夹具，不是板测；构建、快照比对和实屏验收分别记录于 [ENGLISH](../context/ENGLISH.md)。

## 板端翻译方向切换（2026-10-21）

当前 ARM TLS 双语字幕终端提供顶部方向按钮和两行下拉菜单，选项仅为 `English → Chinese` / `Chinese → English`。复用当前字体、浅色背景、圆角与青绿色选中点；覆盖在字幕卡片上方，不挤动 L1/T1 卡片。几何位置由 [ui_layout.h](../../software/subtitle_ui/ui_layout.h)同时供绘制和触摸命中使用。

- 点击标题展开或收起；点击同一选项、或菜单外空白，只收起，不重连；跨行拖动不触发选择。
- 选择另一方向时更新标题、模式标记和目标语言标题；清空旧方向字幕/记录，保留字号和原文开关，并更新 epoch，拒绝旧连接迟到结果。
- 正在运行则关闭旧连接并按新源语言/目标语言重建会话，右侧 Connecting → 已就绪后再说话；暂停或尚未开始时选择不会偷偷开始采音。
- 字幕构建继续只请求文本，保留本地回环。英译英与中文独立 ASR 保留各自显式构建；不扩展到菜单，也不让未实现运行期重连的旧非 ARM 构建显示菜单。
- 模型尾部新增方向和展开状态，模型/快照为 11392/11456 字节；64 字节 CPU1 反馈 ABI 保持，前 7 类命令仍在 accepted[7]，扩展语言控件计数使用原 reserved 槽。

用户已完成中译英、切回英译中及字号实屏短验收，详见[本轮验证](../validation/language-picker-20261021/README.md)。浏览器原型仍属早期演示，未将其鼠标操作当作板端触摸结果。

## 原型实现边界

- `output/ui/index.html` 是无依赖、可本地打开的交互样稿；样例字幕、输入波形和连接状态全为模拟。
- 页面不读取麦克风、不请求网络、不调用模型，不依赖 CDN；示例与真实能力明确区分。
- 产品区域始终有“演示”标识。故障注入面板放在屏幕预览外，不占实际终端版面。
- 导出只包含当前演示中的定稿文字；刷新页面不默认保存历史。正式产品持久化策略另行实现。
- 尊重系统减弱动画设置；指示条只在运行时变化，暂停后停止。核心阅读不依赖动画。

## 验收检查

本轮检查对象仅为浏览器原型；正式设备另走 RUNBOOK P2/P3。

1. 1024×600 下标题、字幕、源文本、历史、底栏和弹层均可见，无重叠或水平溢出；三档字体和长句可阅读。
2. 开始后可观察到原文草稿、翻译状态和中文定稿；历史只增加最终段，不重复存草稿。
3. 暂停/清空取消正在进行的段，旧计时回调不污染当前会话；清空取消路径保留记录。
4. 字号与原文开关有效；设置、记录详情、确认框能打开、关闭并恢复焦点；键盘可操作主要功能。
5. 缺少音频、断线、过载、静音都有明确文字；恢复不会偷偷宣称真实硬件或模型已工作。
6. 普通文本关键配色对比达设计目标；主触控目标至少 56×56 逻辑像素；窄窗口预览比例正常。
7. 无 JavaScript 运行错误、无外部资源请求；截图目视检查。自动检查通过不代表用户已经认可外观。
